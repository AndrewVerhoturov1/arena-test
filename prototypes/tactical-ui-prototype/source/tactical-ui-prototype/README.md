# Тактический интерфейс — самостоятельный HTML5-прототип

Прототип не связан с исходным проектом и не требует сервера, сборки, внешних библиотек или сетевого доступа.

## Запуск

1. Распакуйте папку целиком.
2. Откройте `index.html` двойным щелчком в современном браузере.
3. Разрешение, под которое в первую очередь рассчитан экран: 1920 × 1080. Также проверено 1440 × 900.

## Что работает

- выбор бойца на карте и в составе отделения;
- переключение между бойцом и группой;
- обновление нижней карточки;
- смена позы с физическим переходом во времени;
- запрет недоступной позы с объяснением причины;
- четыре режима перемещения и показ их влияния;
- построение маршрута нажатием по карте;
- два независимо настраиваемых участка маршрута;
- подтверждение и отмена приказа;
- семь информационных слоёв и общая прозрачность;
- пауза и скорости ×0,5, ×1, ×2, ×4;
- уведомления четырёх уровней;
- обычное, предупреждающее и критическое оформление;
- сворачивание левой, правой и нижней панелей;
- всплывающие подсказки и памятка по клавишам.

## Управление

- `Пробел` — пауза или продолжение;
- `R` — построение маршрута;
- правая кнопка мыши на карте — сразу построить маршрут;
- `1–7` — переключение слоёв;
- `G` — выбрать отделение;
- `E` — показать следующее событие;
- `Esc` — отменить текущее действие.

## Структура

- `index.html` — разметка;
- `styles.css` — зрительная система и адаптация;
- `data.js` — демонстрационные данные;
- `state.js` — чистая логика состояния;
- `app.js` — отображение и взаимодействия;
- `assets/tactical-map.png` — локальная подложка карты;
- `tests/state.test.js` — автоматические проверки переходов состояния;
- `docs/ANALYSIS_AND_DESIGN.md` — анализ исходного интерфейса и новая схема;
- `docs/previews/` — контрольные снимки экрана.

## Проверки

Для проверки логики при установленном Node.js:

```bash
node --test tests/state.test.js
```
