# Ручная проверка прототипа

- [ ] Выбрать каждого бойца в левой панели и на карте.
- [ ] Переключить «Боец / Группа».
- [ ] У Барса запросить позу «Лёжа» и дождаться завершения перехода.
- [ ] У Сокола проверить недоступность «Стоя».
- [ ] У Дока проверить недоступность «Лёжа» и пояснение в подсказке.
- [ ] Включить одновременно «Опасность» и «Видимость».
- [ ] Изменить прозрачность слоёв.
- [ ] Построить маршрут и изменить второй участок на «Лёжа / Бегом».
- [ ] Подтвердить и отменить маршрут.
- [ ] Снять паузу и проверить скорости ×0,5, ×1, ×2, ×4.
- [ ] Нажать «Событие» несколько раз.
- [ ] Переключить обычное, предупреждающее и критическое состояния.
- [ ] Свернуть и развернуть все три панели.
- [ ] Проверить клавиши `Пробел`, `R`, `1–7`, `G`, `E`, `Esc`.
